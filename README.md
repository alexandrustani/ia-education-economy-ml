# IA — Tema 1: Învățământ și economie

Coursework for Tema 1 in Inteligență Artificială (IA), focused on machine learning for education and economy data.

## Contents

- `education_economy_ml.ipynb`: analysis and model training notebook.
- `CC_education_economy_train.csv`, `CC_education_economy_test.csv`: public training and evaluation data.
- `Raport_Tema1_IA.pdf`: project report.

Private test data, virtual environments, generated training logs, and submission archives are intentionally excluded. Open the notebook in Jupyter to review the work.
